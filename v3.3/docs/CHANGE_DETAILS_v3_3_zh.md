## 数值修复的精度依据

目标R环境旧函数对a=b=1e-8、[.4,.5]返回-20.016548414999001，独立积分/高精度参考为约-20.016548394229577，绝对误差2.07694e-8；允许误差2.00165e-9。结果有限且区间并不几何狭窄，所以原回退条件漏掉它。修改后该例在所显示双精度上与参考一致。

新增保护仍然积分原始Beta密度，不改变概率分布。小形状是额外保守保护；尾差检查针对实际选择的那一侧，避免另一侧回退后检查错分支。独立积分的误差估计是运行门槛，312例高精度比较是实测证据，两者均不构成任意浮点输入的无限精度证明。
