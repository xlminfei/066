# 旧积分触发阈值的追加复核

本目录保留 tail log-CDF gap 阈值为 1e-7 的完整原始证据。原测试 status.json 的 PASS 对应当时预设的 log 概率绝对误差 <3e-7、梯度尺度误差 <3e-6。它不代表通过更严格的发布审计。

追加核对发现：lo=0.2、hi=0.8、a=1.80354921488859e-08、b=3.60709842977718e-08 时，所选两尾的 log 差约为 1.00010000281259e-07，刚好位于旧直接积分阈值外侧。Stan log 概率为 -17.2166076953689；独立 R 密度积分参考为 -17.2166079436348；绝对误差为 2.4826583455706e-07。

该误差不满足发布审计的 abs(error)<1e-10*max(1,abs(reference_logprob))（本例约 1.72e-9）。没有放宽审计容差。生产修正是把直接积分触发阈值扩展到 1e-4，保留相同 Beta 目标及无 epsilon 的概率定义，并重新编译、验证现行阈值两侧以及这些旧反例。最终结果位于 review/beta_after/ 和 review/beta_switches/，本目录仅为历史证据。

本目录的旧生产源码、测试脚本、probe 及编译 RDS 可以复现原误差。
