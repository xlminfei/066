# v2 省略的大体积运行对象

GitHub 包没有提交后验 `*.rds`、Stan 编译缓存和完整运行目录。它们包含数十亿字节的二进制对象，不适合普通 Git 历史，也不是理解算法所必需的源文件。发布包保留了输入、源码、参数、运行日志、诊断 JSON、结果 CSV、图件、图注和外部预测例子；使用相同输入、随机种子、软件版本和命令即可重新生成后验对象。

正式运行目录中的 RDS 共 247 个、约 15.1 GB（包括准备对象、15 个全资料拟合和 225 个分组留出拟合及其保存对象）。完整运行时它们由 `v2_pipeline.R` 写入 `runs/formal_v2/`；`audit_completed_run_20260919.R` 读取它们并产生紧凑审计表。完整 v2 日志另存为 `v2_run_logs.tar.gz`；postprocess 中被省略的 84 个旧 F06 文件列在 `postprocess_omissions.csv`，它们均被 corrected F06 输出替代。若要保存一份可长期归档的后验样本，建议在本地运行完成后另行使用带校验和的对象存储。
