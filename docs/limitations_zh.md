# 结果解释边界

1. 资料量很小。分类只有 50 个可分类物种，定量只有 51 个有定量资料物种，且若干物种有多个记录。分组留出避免同一物种泄漏，但不能创造新的独立物种。
2. Site151 在响应物种中恒为 C，所以 v2 不估计它的效应。它不是“证明没有生物学作用”，而是说明当前数据不能识别一个 Site151 变化效应。
3. 未见类别和缺失输入仍会输出数值，但它们可能主要由先验和其他位点驱动。解读时必须保留 `Status`，不能把这类结果当作与训练中反复出现的类别同等可靠。
4. ELPD 是预测评分，不是生物学机制证据。AUC 只评价 High/Low 排序，不能评价定量比率的数值误差。MAE 不适合直接处理只有上下界的 interval。
5. paired SE 和近似 p 值按物种聚合，属于辅助比较；表中的 BH 是探索性全表校正。没有预先定义的确认性检验计划时，不应写“统计学显著优于”。
6. Scheme A 不是 beta-binomial 的替代真理，而是一个敏感性假设。其训练资料 PPC 仍有需要人工查看的项目，不能只看 HMC R-hat 就宣布该路线充分描述资料。
7. v2 的模型是固定参考比对下的序列特征模型。新物种必须使用相同参考序列和位点编号；如果重新做比对、换参考序列或改变缺口处理，输入变量已经改变。
8. 365 物种面板是编码和外部预测宇宙，不代表每个物种都拥有实验标签。没有实验资料的物种的结果是模型外推，后续实验验证应作为独立验证，而不是把预测值再写回训练表。
9. 公开仓库中的精简包没有包含大体积后验 RDS 和编译缓存。它包含生成这些对象的源代码、输入、参数、结果表和诊断摘要；复现者需要重新抽样并保存自己的运行目录。
