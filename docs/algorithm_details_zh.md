# 算法和评价指标：给没有建模背景的读者

## 1. 输入资料怎样进入模型

每个物种有一个已经对齐并提取好的六个位点序列。实验记录不要求都能转成一个精确百分数：

- `count`：例如 2 个响应、总数 10 个，写成 `Events=2, Total=10`；
- `exact`：只知道报告比例，例如 0.37，但不知道原始分母；
- `interval`：只知道比例在 `[Lower, Upper]`，例如 0.40–0.50。

High/Low 只是用于分类评价：点值小于 0.5 是 LOW，大于等于 0.5 是 HIGH；区间上界小于等于 0.5 是 LOW，下界大于等于 0.5 是 HIGH；严格跨过 0.5 的区间不进入分类。定量路线仍使用原始 count、exact 和 interval，不把区间硬改成中点。

## 2. High/Low 模型

对每个物种把 High 次数记为 `HighCount`，可分类的总次数记为 `Trials`。模型使用现成的二项分布和 logit 链接：

`HighCount ~ Binomial(Trials, p)`，其中 `p` 是给定五个位点后该物种成为 High 的概率。

Null 没有序列变量；Site315 只有 Site315；M1、M2、M3 使用五个位点的不同编码。输出的 `Point` 是后验平均 High 概率，`CrI_lower/upper` 是这个概率的 95% 后验可信区间。

这里的“后验”可以理解为：先给参数一个温和的先验范围，再用已有实验资料更新它。未见过的类别仍可计算，但因为没有相应实验记录，结果更多依赖先验和其他位点，必须看 `Status`。

## 3. 联合 beta-binomial 比率模型

这个模型直接建模一个共同的物种期望比率 `m`。count 记录保留真实分母，并用 beta-binomial 允许重复实验之间比简单二项分布更分散：

`q ~ Beta(phi*m, phi*(1-m))`，`Events ~ Binomial(Total, q)`。

其中 `m` 是物种层面的中心比率，`phi` 是计数精度；`phi` 越大，实验比例越接近 `m`，越小则允许更大的实验波动。exact 记录使用“连续 beta 部分 + 1 端点质量”的现成概率构造；interval 记录使用同一分布在区间内的概率。三种记录共享同一个 `m`，所以 count、exact、interval 的资料能够联系起来，但没有把未知分母凭空补成一个整数。

输出三种东西：expected exact-report ratio 的后验均值、其 95% 后验可信区间，以及从后验预测分布生成的未来一个 exact 型报告的 95% 后验预测区间。后者表示未来一条报告可能落在哪里，不需要事先猜未来实验会使用多少个个体。

## 4. Scheme A 敏感性路线

Scheme A 把报告比例看作一个观测值，并用 `brms` 的删失正态接口处理区间记录。它保留同一个输入数据和位点设计，但对 count 的分母信息不作为似然精度，因此是一个有意不同的敏感性假设。它的点值、CrI 和 PI 单独展示，不能与 beta-binomial 的数值混成同一个主估计。

## 5. AUC、ELPD 和 MAE 分别回答什么

- **AUC** 只用于 High/Low：把物种按预测 High 概率从高到低排序，看 HIGH 是否大体排在 LOW 前面。AUC=0.5 相当于随机排序，越接近 1 区分越好。v2 的主分类 AUC 是各留出折 AUC 的平均，不把所有折的分数不加区别地拼成一个主指标。
- **ELPD** 是留出记录的预测对数密度总分。分数越大表示对未见记录的概率预测越好；差值相对 Null 为正表示更好。它可以用于 High/Low，也可以用于定量路线，但两个路线的记录和似然不同，不能混为一个数。
- **MAE** 是预测值与观测值的平均绝对差，只作为定量路线的直观辅助。区间记录没有唯一观测点，因此主 MAE 只对可定义的点值记录汇总。

v2 还按物种聚合逐条留出 ELPD，计算配对 SE、95% 正态近似区间和未校正/BH 辅助 p 值。它们是模型比较的辅助证据，不是生物学效应显著性检验；多重比较校正后的结果不能写成“统计学显著优于”除非预先定义的检验计划支持这一表述。

## 6. 五折、十折和样本单位

折分按物种做，先把一个物种的所有记录放在同一个折里，再用其余物种训练、该折物种测试。因此同一物种不会同时出现在训练和测试。分类路线有 50 个可分类物种；定量路线有 51 个有定量资料物种。5 折是主评价，10 折是敏感性；它们主要影响评价的不确定性和训练/测试组合，不改变最终用全部资料拟合的预测模型。

## 7. 先验与未见类别

固定设计列在训练时全部保留，系数使用 `Normal(0,0.5)`，截距使用 `Normal(0,1.5)`，端点质量使用 `Beta(1,1)`，count 精度在 log 尺度使用 `Normal(log(10),1)`。这些是透明的工作先验，不是从结果反推的真值。未见类别对应的系数没有被实验资料更新，所以数值可以输出，但必须标记为外推，不能说该类别已经被数据验证。
