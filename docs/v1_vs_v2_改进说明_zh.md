# v2 相比 v1 的改进、变化和原因

这两个版本使用同一研究问题和同一批 365 个物种面板，但 v2 重新固定了模型对象、编码、验证口径和新物种接口。v1 保留作历史结果；发表和新物种预测优先使用 v2。

## 一览表

| 内容 | v1 | v2 | 为什么修改 |
|---|---|---|---|
| 候选结构 | Null、Site315、M1/M2/M3，各有无树 U/P，共十个结构 | Null、Site315、M1/M2/M3，共五个结构 | 用户要求完全去掉进化树，避免在小样本下得到极宽或 NA 的 P 路线预测 |
| Site151 | 输入中保留；在有响应物种中为常数 C，实际没有可估计变化 | 输入和审计中保留，但从五个位点预测矩阵中明确排除 | 常数列不能提供训练信息；显式排除避免读者误以为 Site151 被估计了效应 |
| M1 | 采用旧版设计，Site315 的 R 作为单独类别 | 各位点为参考类别、`other`、`MISSING`；Site315 为 `K_or_T`、`other`、`MISSING` | 原始研究关注 K/T 是否可被泛素化；R 与其余非 K/T 合并更符合目标问题，并统一缺失口径 |
| M2 | `CKST` 与 `non_CKST` 的旧名称/设计 | `CKST`、`other`、`MISSING` | 把生物学归类和缺失状态分开，保证完整设计列固定存在 |
| M3 | 随当时响应资料动态生成类别 | 按冻结的 365 物种面板逐位点统计；出现 1–3 次（<1%）合并 `OTHER`，至少 4 次保留，`MISSING` 单独保留 | 后来增加一个物种不能改变已经发布的类别字典；避免把 1% 阈值写成模糊的 3/4 次判断 |
| 设计矩阵 | v1 的固定效应做过面板均值中心化 | v2 使用固定、未中心化的完整 dummy 设计列 | 新物种类别、基准类别和缺失列的含义更直接；避免类别加入/删除时重新解释截距 |
| 点估计 | 主要手册使用后验中位数 | v2 结果表的 `Point` 使用后验均值 | 对概率和 expected ratio 的定义统一，均值也直接对应后处理和绘图代码 |
| 计数似然 | 旧代码框架包含计数/精确/区间联合路线 | v2 明确使用 beta-binomial：`alpha=phi*m`、`beta=phi*(1-m)` | 保留真实 Events/Total，同时允许重复实验的过度离散；修正了旧版计数精度参数错误相加的问题 |
| Scheme A | 作为旧版数值路线的一部分 | 作为独立的删失正态敏感性路线；使用现成 `brms::cens`，保留 count/exact/interval 的追踪 | 给出用户要求的方案 A 对照，但不把它和联合 beta-binomial 混成同一个 estimand |
| 未见类别 | 某些输出会整行 NA 或依赖是否在训练记录中出现 | 仍输出数值，`Status` 标记 `unseen_category_extrapolation`；缺失标记 `missing_input_extrapolation` | 新物种必须始终得到 High 概率和比率范围；未见类别的数值主要由先验外推，状态不能省略 |
| 验证分组 | 旧版包含树距离/聚类路线 | 5 折为主，10 折为通过门控的敏感性；分类固定 50 个可分类物种，定量固定 51 个有定量资料物种 | 不把“50 个分类物种”和“51 个定量物种”混为一个折表，也不让树结构影响主结果 |
| 评价 | LOO/ELPD 与树模型混用 | 逐条留出记录的 ELPD；High/Low 用折内 AUC；MAE 只作定量辅助；不使用 ΔAUC | 小样本、分类折分和区间资料下，逐条留出更易核查；AUC 与 ELPD 回答不同问题 |
| 新物种输入 | 依赖完整工作目录和历史手册状态 | 固定比对后六个位点表，输出长表和宽表；Site151 读取但不进模型 | 让外部使用者不需要重新做多重比对，也不会因为面板增加而改变模型 |
| F06 图 | 旧图分页时物种标签与行值可能错配，来源表只写入部分模型 | corrected 版本以同一行号绘图，九页各包含 42×5=210 行来源表 | 修正用户发现的 Cirrhinus molitorella、Danio rerio 图上看似全部高于 0.5 的显示错误 |

## F06 显示错误的具体修正

旧代码先把绘图行号反转，再把标签也反转，导致标签和数据行的配对关系不再明确；来源 CSV 还通过 `match()` 只保留了每个物种的第一条模型记录。修正后使用 `y=1..n` 与 `scale_y_reverse()`，来源 CSV 保留该页所有物种和五个模型。数值表中的 Cirrhinus molitorella 和 Danio rerio 的 M1/M2/M3 High 概率点估计均低于 0.5；应使用 `F06_*_corrected` 图件，不使用没有 `corrected` 后缀的旧图。

## 这些改动对结果解释的影响

v2 与 v1 不是只改文件名。类别参数化、是否中心化、点估计统计量、是否包含树随机效应和 Site315 的类别边界都会改变系数的含义，因而不应把 v1 的点估计当作 v2 的重复计算。两版的输入物种和原始响应记录可追溯，但正式结论应引用 v2 的编码合同、留出表和 corrected 图件。
