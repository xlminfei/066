**06A的ROC/AUC实现已加入并在Ubuntu环境中验证。这里的运行结果使用虚构数据，不是正式研究数据的预测成绩。**

以下是v2新增ROC算法时的历史验证记录。v3的分类边界另见[分类边界更新说明](分类边界更新说明.md)；正式v3分析需要按新标签重新拟合分类模型和CV，不能直接复用旧标签的AUC结果。ROC计算算法本身没有改变。

这次新增6个带注释的R命令块，仍可在控制台逐块输入，没有新增用户自定义函数或脚本加载器。已有00–08的36个R代码块保持相同，因此原输入准备、两条路线的模型、先验、ELPD参照与07预测定义不变。已有v1的有效拟合和CV结果可以复用。

新增功能采用pROC 1.19.1。主指标为每折AUC的算术平均`CV_AUC`，同时保存每折AUC与原始ROC坐标；不同折的分数不拼成一个主AUC。方向固定为较高概率对应High；同分按标准规则计入，低于0.5的AUC保持原值。

| 已完成检查 | 结果 |
|---|---|
| 已知配对例子 | 3/4配对排序正确时AUC=0.75 |
| 反向排序 | 对应AUC=0.25，未被自动翻成0.75 |
| 全部分数相同 | AUC=0.5 |
| 跨折分数存在整体偏移 | 使用折内AUC；未错误替换为合并分数的面积 |
| 某一折只有High或只有Low | 标记无法定义；完整CV_AUC留空，不删除该折后平均 |
| 未见水平和不可估方向 | 保留记录、预测与标记 |
| 输入错误 | 缺失分数、越界概率、重复记录、同物种跨测试折、未知真实标签均拒绝 |
| ROC坐标与AUC | 导出坐标的曲线面积与已知AUC一致 |
| 已有结果身份 | 改变折分配、父模型或实验标签时明确拒绝 |

实际接入了原验证运行中的10个分类模型、每个2折，共20套已有留出拟合。每个模型评价57条可分类实验（26条High、31条Low）；3条无法明确分类的记录没有伪造标签。新增导出570行实验级留出概率和72行ROC坐标。概率直接由留出拟合在`Trials=1`时重新计算，未重新训练模型。

20个“模型×折”AUC均另外用所有High/Low配对进行独立核算，最大差异为1.12×10^-16。Null_U各折AUC均精确为0.5。测试中出现的低AUC如实保留；验证通过只表示计算正确，不表示每个模型有较强区分能力。

ROC的PDF输出共10页，每个模型一页，显示该模型各折曲线、每折AUC及折平均AUC。已核对页数、模型名、坐标轴、每折图例和页面文字边界，并检查代表性页面渲染。虚构数据的图与表放在`验证证据_ROC`，仅供核查实现。

正式运行主要得到：

| 文件 | 内容 |
|---|---|
| `auc_summary.csv` | 每个模型的CV_AUC、各折范围、有效折数、记录数量和支持标记计数 |
| `auc_by_fold.csv` | 每个模型、每一折的AUC与High/Low数量 |
| `roc_oof_experiments.csv` | 每条可分类实验的真实标签、折编号、留出High概率和支持标记 |
| `roc_coordinates_by_fold.csv` | 每个模型、每一折的阈值、FPR和TPR |
| `auc_source_receipts.csv` | 追踪使用的模型、CV身份和文件哈希 |
| `roc_by_model_and_fold.pdf` | 执行可选ROC绘图块时生成的10页ROC图 |

每折AUC的最小值和最大值不是95%置信区间。本版没有对相关的重复实验直接套用独立观测的DeLong区间，也没有把极少折的波动当成精确的总体区间。正式比较还需考虑有结果物种数量、亲缘相关性和不同划分的稳定性。

用户排除的ELPD差值图、分类概率校准图和定量预测与观测图未加入此次代码。ELPD仍采用原先的比较方式；没有将site315设置成新的统一参照。定量其它指标目前作为方法说明提供，未擅自增加新的计算任务。
