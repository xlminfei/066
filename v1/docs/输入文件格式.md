**正式运行只需要三份输入文件：sites.csv、observations.csv、tree.nwk。**

把它们放到你新建项目的`input`目录。不要直接覆盖旧目录的文件。`blank_input`提供只有表头的CSV；`demo_input`提供8个虚构物种的练习材料，不能用于正式结果。

**sites.csv：每个物种一行，记录六个位点/状态。**

表头必须包含：

```csv
Species,Site3,Site20,Site117,Site151,Site196,Site315
```

| 列 | 填写要求 |
|---|---|
| Species | 与树末端名称完全相同；不能重复、不能空白 |
| 六个Site列 | 按原来六个位点的定义填写单字母状态；本版保留原M1/M2/M3分类约定 |

正式面板默认365个物种。没有比率资料的物种也保留在这里和树中。不要把参考序列位置直接当作另一次比对的列号；输入位点的同源对应关系必须来自你已核对的资料，本程序不重新定位或替换序列。

空值、NA、X、短横线和旧INDEL统一进入新增编码中的MISSING。原始六列保留，MISSING是显式分类状态，不是自动插补的结果。除20种常用氨基酸单字母和这些缺失符号外，发现其他状态时程序会停止，避免悄悄改变编码。

**observations.csv：每行是一份独立实验组的结果。**

固定表头：

```csv
RecordID,ExperimentID,Species,Type,Events,Total,Exact,Lower,Upper,SourceID
```

| 列 | 含义 |
|---|---|
| RecordID | 本行唯一编号，例如R0001；始终保留以便追踪 |
| ExperimentID | 全局唯一的独立实验组/预定观察终点编号，例如Ref01_GroupA_End1 |
| Species | 与sites.csv及树完全匹配 |
| Type | 只能为count、exact或interval |
| Events | count行中达到预定响应标准的个体数 |
| Total | count行中接受观察的总个体数 |
| Exact | 分母未知但报告具体比率的exact行填写 |
| Lower、Upper | 真正区间的下界和上界 |
| SourceID | 可追溯的来源编号；可重复，不进入研究/条件分组模型；不必填写未公开的详细内容 |

三类记录互斥，填写规则如下：

| Type | Events | Total | Exact | Lower | Upper |
|---|---|---|---|---|---|
| count | 必填非负整数 | 必填正整数 | 留空 | 留空 | 留空 |
| exact | 留空 | 留空 | 必填，0<Exact<=1 | 留空 | 留空 |
| interval | 留空 | 留空 | 留空 | 必填 | 必填 |

你已确认本次真正区间的总个体数均未知，因此interval行的Total保持空缺。count行需满足Events<=Total，Total不超过Stan整数范围；不能把多次行为发生数当作达到标准的个体数。

示例只说明格式：

```csv
RecordID,ExperimentID,Species,Type,Events,Total,Exact,Lower,Upper,SourceID
R0001,Ref01_GroupA,Synthetic_1,count,8,20,,,,Ref01
R0002,Ref02_GroupA,Synthetic_2,exact,,,0.75,,,Ref02
R0003,Ref03_GroupA,Synthetic_3,exact,,,1,,,Ref03
R0004,Ref04_GroupA,Synthetic_4,interval,,,,0.4,1,Ref04
```

填写时应遵守：

- 比率使用0–1，不带百分号；75%填0.75，100%填1。
- 分母未知就留空，不填0、100或从小数位数反推分母。
- count同时报告分子/分母及比例时只保留这一条count，不再额外输入一条exact。
- 独立实验分别报告0.2、0.4、0.8时保留三行，不压缩成0.2–0.8。
- 同一批个体的重复时间点、技术重复或重复报道，不能仅靠改ExperimentID就变成独立证据；应先按你的分析范围确定一致的观察终点并去重。
- 只有“一次观测的结果确实位于某区间”的资料才用interval；多实验极差、置信区间和笼统范围不能直接当作这种观测。
- interval必须满足0<=Lower<Upper<=1。不能取中点，也不能把两个端点拆成两行。
- 本版允许count中的Events=0；未知分母的精确0不在你已确认的输入范围中，程序会明确拒绝而不修改数值。
- ND或没有结果的物种不在observations中补一行0；保留在sites和tree等待预测。

CSV可以用Excel准备，但保存前把数值列设为普通数值，避免导出的CSV仍包含百分号；编号列和Species列按文本保存，避免Excel事先删去编号前导零。使用CSV UTF-8格式。打开CSV文本确认表头和数字形式。程序先按字符读取，再显式转换规定的数值列，以保留F/T等单字母状态与文本编号。不要靠单元格颜色表示数据类型。

**tree.nwk：使用你已经定根的那一棵树。**

要求只有一棵Newick树，具有有效枝长，末端名称与sites.csv完全一致。程序计算与原约定一致的相关矩阵A，并保存其数值身份。它不会重新定根、剪树、补物种或静默修补非正定矩阵。模板不提供虚构的365物种树；请使用你已核对的文件。

**你不需要手工制作HighCount/LowCount或Stan输入数组。**

01会从实验明细自动生成每个物种的HighCount、LowCount、Trials和未分类数量。本版按2026-09-11确认的规则：点值或计数比率小于0.5归Low，大于或等于0.5归High；真实区间上界<=0.5归Low，下界>=0.5归High；只有Lower<0.5且Upper>0.5的严格跨越区间不增加分类次数。

例如40%、0/N、40–50%归Low；50%、50–100%、75%归High；40–100%和20–55%不参与High/Low及ROC/AUC。你已确认0%有分母或只是举例；有分母时继续按count填写Events=0和真实Total。

40–50%归Low是按报告形式采用的分类约定，并没有把原区间修改成40–49.9%。03仍完整使用原始Lower=0.4、Upper=0.5；07的期望比率定义也没有改变。若上下界都等于50%，它是精确50%的点值，应填exact=0.5，不填零宽度interval。

程序能检查编号、格式和数学约束，不能仅凭CSV证明实验真正独立或文献结果可比。这部分需由来源核查保证；不需要向程序或外部服务提供研究关键词。

旧版只有物种汇总比例的`ratio.csv`不能直接替代新版`observations.csv`。需要回到独立实验明细，填写能核实的分子/分母和记录来源；仅凭汇总比例不能自动恢复这些信息。
