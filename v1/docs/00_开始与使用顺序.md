**这是一套在 Ubuntu 的 R 控制台中分段输入的操作指南。**

不需要执行任何 `.R` 脚本，也不需要用 `source()` 加载代码。03的Stan模型说明完整放在一个R字符串中，随后调用现成程序编译和拟合。一个包含括号或循环的表达式要输入完整才会执行；看到`+`提示符表示上一条尚未输入结束。

正式分析顺序：00设置环境 → 01准备输入 → 02独立分类与03联合比率分别拟合 → 05先运行读取和抽样诊断 → 04模型检查与必要的敏感性拟合 → 05复核新增拟合并比较 → 06按物种/系统发育距离留出验证 → 07输出全部物种的概率与期望比率区间。08为可选的完整树矩阵/子矩阵数值检查。文件编号沿用原流程，但04读取的是05已检查的对象，因此首次使用时要先到05完成诊断。

任何步骤报错都应先停止，修正当前问题后从该完整代码块重新开始。不要继续使用一个只执行了一半的对象。原来的目录和RDS不参与本版缓存。

在Ubuntu终端逐行输入。下面创建的是新工作目录；你也可以换成自己选定的新目录。

```bash
mkdir -p "$HOME/ratio_workflow_v3/input"
cd "$HOME/ratio_workflow_v3"
pwd
R --vanilla
```

进入R的`>`提示符后，输入以下设置。先把三份输入放到新目录的`input`子目录，格式见《输入文件格式》。示例数据位于本交付的`demo_input`，仅用于练习，使用示例时将`EXPECTED_SPECIES`改为8；正式面板默认365。

PROJECT_DIR <- getwd()
INPUT_DIR <- file.path(PROJECT_DIR,"input")

这些先验是明确的起始工作选择：系数和系统发育尺度沿用原框架；新增端点贡献比例使用均匀Beta先验，精度在对数尺度使用正态先验。它们不是由稀少资料自动确定的客观真值。不要依据得到的结果反复调参去追求特定结论。

检查包。包名后的`::`表示调用这个包里的现成函数。`binomial()`等只是指定分布，真正拟合由brms或RStan完成。

目录保护与会话设置：

<!-- R_BLOCK:00_RUN_DIRECTORY -->
```r
if (!RUN_MODE %in% c("new","resume")) stop("RUN_MODE只能是new或resume。")
if (RUN_MODE == "new" && dir.exists(RUN_DIR)) stop("运行目录已存在：请改RUN_TAG，或明确使用resume。")
if (RUN_MODE == "resume" && !dir.exists(RUN_DIR)) stop("要恢复的运行目录不存在。")
if (RUN_MODE == "new") dir.create(RUN_DIR,recursive=TRUE,showWarnings=FALSE)
for (folder in c("fits","results","cv")) dir.create(file.path(RUN_DIR,folder),showWarnings=FALSE)
rstan::rstan_options(auto_write=FALSE)
options(mc.cores=CORES)
package_versions <- character(length(needed)); names(package_versions) <- needed
for (pkg in needed) package_versions[[pkg]] <- as.character(utils::packageVersion(pkg))
print(package_versions)
if (RUN_MODE == "resume") {
  prepared <- readRDS(file.path(RUN_DIR,"prepared.rds"))
  if (!identical(prepared$version,MODEL_VERSION)) stop("这不是当前版本的准备结果。")
  for (name in names(prepared$input_paths)) {
    current_hash <- digest::digest(file=prepared$input_paths[[name]],algo="sha256")
    if (!identical(current_hash,prepared$input_hashes[[name]])) stop("输入已经更改，请创建新运行。")
  }
}
```

新运行继续01。恢复运行不重复保存01，直接进入需要的模型步骤。每次正式输出都保留原始输入哈希、模型说明、先验和软件版本；重复运行不会把旧模型换个名字当作新结果。

如果上次在01成功保存`prepared.rds`之前就报错，该运行还不能使用`resume`恢复。修正输入后换一个新的`RUN_TAG`并使用`new`即可，保留原目录便于查看报错。恢复联合拟合、联合留出或08联合矩阵检查时，在当前会话重新执行03的模型字符串和编译块；已存在且身份一致的拟合会直接读取。

不要把多行代码压成一行，也不要把中文解释当作命令输入。以`#`开头的代码注释可以一起复制；一个代码块整体复制到R控制台是允许的，不是在执行脚本文件。关闭R或服务器断连前，可完成当前模型的保存块，下一次从`resume`继续。
