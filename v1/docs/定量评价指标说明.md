**定量路线并不只能使用ELPD。本次新增的是High/Low的ROC/AUC；下面说明其它定量指标的适用范围，不自动增加这些指标或图。**

| 指标 | 浅显含义 | 对当前资料的适用范围 |
|---|---|---|
| ELPD | 模型给实际结果分配的预测概率或密度有多合理 | 现有联合模型可对计数、点值和真实区间评分；比较需保持记录集合与留出单位一致 |
| MAE，平均绝对误差 | 一个点预测平均离实际点值差多少 | 可在有明确点结果的记录上计算：count使用Events/Total，exact使用Exact；不能给interval填中点 |
| RMSE，均方根误差 | 也是点误差，但较大的错误受到更强惩罚 | 同样需要明确的实际点值，并说明是按实验等权、按物种汇总，还是其它预先规定的权重 |
| CRPS | 用整条预测分布评价结果，兼顾位置与分散程度 | 普通CRPS需要观测点值；区间/删失记录需要另外选择适用的评分方式，不能直接用区间中点 |
| 预测区间覆盖与宽度 | 下一次实验结果落入预测范围的频率及范围有多宽 | 需要未来结果的后验预测分布；不能直接使用07的整体期望后验区间来声称95%实验应落在其中 |

例如比率使用0–1尺度时，MAE=0.08表示平均绝对偏差为8个百分点。RMSE更容易被少数大误差拉高。它们都能补充ELPD，但评价目标不同，不保证给出相同模型排序。MAE/RMSE的现成实现可参考[loo预测指标说明](https://mc-stan.org/loo/reference/loo_predictive_metric.html)；该接口依赖PSIS近似有效，当前近似失败的情形应使用06的实际留出预测计算，不能绕过诊断。

只有区间[L,U]时，并不知道真实结果具体是哪一个数。把它改为中点后算MAE/RMSE，会把未知的事实伪装成已知。因此，若补充这些误差指标，应明确写成“在有实际点结果的记录子集上评价”，并对所有候选模型使用相同子集。三类资料仍共同参与原联合拟合，不因某个辅助指标暂时不能评价区间就把区间从训练中删除。

CRPS可以用现成包对相应的预测分布或模拟抽样计算，见[scoringRules文档](https://cran.r-project.org/web/packages/scoringRules/scoringRules.pdf)。这里需要的是与观测类型一致的结果预测分布；07保存的m抽样描述整体平均水平的不确定性，不能自动当作下一次实验结果的分布。

若重点是目前这批混合形式资料的模型比较，可继续把覆盖全部记录的ELPD作为一项主要评分，再用明确点值子集的MAE/RMSE补充“平均差了多少”的直观解释。单独的相关系数不能代替误差：一个模型即使把所有比率都系统地高估一截，仍可能具有很高的相关性。

自行绘图时，请区分原始输入与模型导出的评分/留出预测。ELPD差值需要模型评分表，分类校准需要留出概率，预测与观测对照也需要对应的预测结果，不能仅由尚未建模的输入表获得。此次没有新增你排除的三类图，也没有把site315改成ELPD统一参照。
