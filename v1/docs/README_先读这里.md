**这是v3操作手册，包含2026-09-11确认的分类边界，以及2026-09-12修正的M3稀有类别阈值；仍在Ubuntu的R控制台逐块执行。**

本版把40–50%这类上界恰好为50%的区间归入Low；精确50%以及下界为50%的区间仍归High。只有Lower<50%且Upper>50%的严格跨越区间不参与分类。完整规则及验证见[分类边界更新说明](分类边界更新说明.md)。已加入的[06A：High/Low ROC与AUC](06A_HighLow_ROC_AUC.md)继续保留，也没有改变ELPD的参照方式或增加此前排除的三类图。

M3现在按固定365物种参考逐位点统计，把出现频率小于1%的氨基酸类别合并为`OTHER`：出现1、2、3次合并，至少4次保留，`MISSING`单独处理。00中的默认设置已由`RARE_MIN=3L`修正为`RARE_MIN=4L`；两条分析路线使用同一套编码。具体影响及本次检查见[OTHER合并阈值更新说明](OTHER合并阈值更新说明.md)。

先看[输入文件格式](输入文件格式.md)，再从[00：开始与使用顺序](00_开始与使用顺序.md)操作。所有待执行命令均写在 Markdown 的代码块中，并有中文说明。交付中没有需要执行的 `.R` 脚本，也不需要用 `source()` 加载程序。

每个带括号或循环的代码块是一条或数条完整表达式。可以将一个完整块复制进 R 控制台；逐行输入时，等到最后一个括号闭合才会执行。`>`、`+` 是控制台提示符，不要复制进去。Ubuntu 终端命令与 R 命令分开标注。

当前使用`MODEL_VERSION=ratio_manual_v3_boundary50_rare1pct`与新的默认`RUN_TAG`，从00、01开始建立新运行；`resume`只用于恢复版本标识相同的运行。本版不自动迁移旧RDS。此前分类边界变化后的旧High/Low次数、分类拟合及ROC/AUC不能直接作为新分类规则结果；本次稀有阈值修正后，旧M3拟合、验证及预测也不能直接作为新编码结果。定量模型公式与原始区间数值没有改变。

**保留的分析约定。** 六个位点为3、20、117、151、196、315；正式面板默认365个物种，每个物种一套基因型。M1为主编码，M2和M3为敏感性编码；每种编码分别拟合U和P结构，另有四个基线，共10个候选结构。两条分析路线分别进行，所以主拟合一共20个。P使用给定树的相关矩阵；U不使用物种随机效应。

02采用按报告形式规定的分类口径：点值/计数比率<0.5为Low、>=0.5为High；区间上界<=0.5为Low、下界>=0.5为High，严格跨越0.5的区间不增加High/Low次数。03仍使用原始区间。0%有分母时填写count的Events=0和真实Total；未知分母的精确0仍不在当前输入合同中。

**07交付什么。** `species_predictions_long.csv`在365物种时应有2190行，每个物种对应M1/M2/M3的U/P六个模型；`species_predictions_wide.csv`应有365行。`PrHigh`为02的High倾向，`PredictedRatio`为03整体期望比率的后验中位数，`RatioLower95`和`RatioUpper95`为该期望的95%后验区间。它们不是下一次实验结果的预测范围。

未见过的编码水平会保留物种行而把相应数字留空。新组合、依赖先验的未识别方向、缺失状态和没有结果的物种均附有标记；不要去掉标记后把所有预测当作同等可靠。

**练习与正式使用。** `blank_input`中是两个只有表头的CSV。`demo_input`中是8个虚构物种的示例，使用时把`EXPECTED_SPECIES`改成8。示例用于熟悉格式；它不代表你的研究资料，也不保证每个模型或每种折分配都满足正式分析条件。正式数据的来源可比性、独立性和区间含义仍需根据原始资料确认。
