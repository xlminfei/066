# v4 evaluation contract and validation

The production evaluator contains only record-equal training with species-equal evaluation, the binary and joint_bb routes, Null/M1/M2/M3, and the frozen fivefold/tenfold designs. `03_evaluate.R` first checks OOF records against the prepared observations and frozen folds, then writes the ten required evaluation artifacts. It never fits a model.

- Species weights are recomputed on each metric's valid set as `N / (S * n_species)` and sum to that set's record count. Log scores use all informative held-out records. MAE, RMSE, signed bias and predictive-interval coverage/width use count and exact observations only. Interval records are never imputed into point metrics.
- Reported AUC is the unweighted arithmetic mean of all fold AUCs. Pooled AUC remains an explicitly descriptive output and is never the tested AUC. An undefined fold or bootstrap AUC is an error, not a dropped fold.
- ELPD is MeanLogScore multiplied by the full route/design record count. Its single hypothesis test is named `MeanLogScore`; `ELPD_Difference` supplies the scaled effect without creating another hypothesis.
- The 30 non-Null tests form exactly ten families of M1/M2/M3. Families are identified by Route, Metric, Design, TrainWeighting and EvalWeighting. `P_approx` and the percentile CI are retained; `P_BH3` uses `p.adjust(..., method="BH", n=3)` even when a family contains NA. Duplicate, missing, extra and invalid keys/P values are errors. Null remains in descriptive metrics and plots, never in the hypothesis table.
- MeanLogScore retains 2,000 paired whole-design species bootstrap draws and the `20260920 + 100*design_index + route_index` seed. Species are sorted, and the original `sample.int()` index order is retained. AUC retains 50,000 species bootstrap draws within fixed fold and label-composition strata with seed `20260923 + 1000*design_index + 10*fold`. MAE/RMSE share the original paired species multiplicities and seed `20260923 + 1000*design_index + 999`. RMSE takes the square root after computing the complete resample's weighted mean squared error.
- Calibration retains weights computed on the full binary evidence within each bin, with the previous per-bin species resampling order, seed, and support flags. Log-score, point and PI species counts and AUC class-species support remain explicit outputs.
- Degenerate non-Null uncertainty produces a flagged NA P value. Unsupported point metrics retain all required rows as flagged NA. No uncertainty row is silently removed. All intervals and normal-approximation tests condition on the saved OOF predictions, folds and (for AUC) outcome-composition strata. They do not include model-refitting or fold-selection uncertainty and should be interpreted as conditional, exploratory evidence.

## Validation performed

`test_metrics.R` loads the independent v4 code through `load_v4()`. It checks unequal species support, global RMSE, interval exclusion, calibration weighting, ties and missing AUC classes, zero-SE handling, NA-inclusive BH families, complete grids, invalid IDs/folds/P values and the all-interval/no-point boundary. The latter retains 30 total tests with all 12 MAE/RMSE tests flagged NA.

Prior complete passes used the existing image `sha256:c67aade078ec1510b1b036a1a34c6ad0aad66534296b9e6587cd9f283093ca58`, with the repository mounted read-only and networking disabled; those outputs were temporary and removed with the test container. The final release run uses the same image with a writable repository mount and networking disabled, saving its evidence to `validation/v4/metrics_final/` and its full log to `validation/v4/metrics_final.log`.

The suite reevaluates 2,440 saved record-equal OOF rows without MCMC and checks 120 fold metrics, 16 summary rows, 30 hypothesis rows, 15 AUC support rows and the ten-file output contract. The retained run uses the production 2,000 MeanLogScore and 50,000 AUC/error bootstrap replicates, including the final no-point boundary check. All 30 production bootstrap draw vectors, multiplicity groups and eight production CSV tables are retained. After checking the ten production files, the test writes `metric_reconciliation.csv`, `source_sha256_receipt.csv`, `sessionInfo.txt` and `test_status.json`. The SHA receipt covers the saved formal/supplement evidence, six frozen inputs, production code and test source, with before/after hashes. `test_status.json` records the actual result, exact parameters and hashes of the ten production outputs.

To reproduce the retained evidence, invoke `Rscript validation/v4/test_metrics.R REPOSITORY NEW_OUTPUT_DIRECTORY`. The optional second argument must name a new, absent directory; existing outputs are never overwritten. Omitting that argument preserves the original temporary-output cleanup behavior.

Against the saved v3.4/formal supplement, all retained raw P values, CIs, SEs and differences agree within `1e-12`; the observed maximum absolute differences are `5.44e-15` for P and `1.55e-15` for CI endpoints. All AUC/error multiplicity matrices are exactly identical, all 18 saved AUC/error bootstrap difference vectors reconcile within `1e-12`, and all four log-score seed/index sequences match. Raw P/CI reconciliation is numeric within the stated tolerance; no bitwise equality is claimed. Descriptive metrics and calibration limits/support flags also reconcile, with ELPD checked to `1e-10` and explicitly verified as `MeanLogScore * N`.

This validates recomputation of the supplied fixed OOF evidence and the evaluator's input/output contracts. It does not establish the quality of any future v4 model fit or replace the independent sampling diagnostic gate.
