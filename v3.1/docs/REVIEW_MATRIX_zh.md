# v3.1 审查要求—实现—验证对照表

## 发布收尾补充修正

真实接口还发现并修复了零维beta在rstan提取时为NULL的边界、rstan代码附加model_name2属性导致的误拒绝，以及JSON命名向量丢失文件名导致的产物清单漏检。实际拟合载荷指纹改为稳定的数值抽样/采样控制/实际数据/代码摘要，并验证RDS往返。brms会移除未进公式的ID列，因此实际拟合数据核验针对High、TrainWeight和全部设计列；ID仍由外层训练数据及请求身份校验。篡改/调换/陈旧状态负例均按预期拒绝。
